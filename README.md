# XAMAM V1.0.0

Модульная Lua система для Delta Executor с архитектурой на основе загрузчика и отдельных компонентов.

## 📋 Описание

XAMAM - это удобная модульная система, где весь код разделён по файлам и модулям. Проект использует централизованную загрузку из GitHub, позволяя избежать необходимости вставлять огромные скрипты в Delta Executor каждый раз.

## 🏗️ Архитектура

```
XAMAM/
├── Scripts/
│   ├── Main.lua                 # Точка входа для Delta Executor
│   ├── Core/
│   │   ├── Loader.lua           # Система загрузки модулей из GitHub
│   │   ├── Logger.lua           # Единая система логирования
│   │   └── Config.lua           # Управление конфигурацией проекта
│   ├── GUI/
│   │   ├── GUI.lua              # Основной интерфейс XAMAM
│   │   ├── Theme.lua            # Темы и стили (цвета, размеры)
│   │   ├── Components.lua       # Переиспользуемые компоненты (кнопки, переключатели)
│   │   └── Tabs.lua             # Система управления вкладками
│   ├── Functions/
│   │   ├── Functions.lua        # Менеджер функций
│   │   ├── Player.lua           # Функции для игрока
│   │   ├── Combat.lua           # Боевые функции
│   │   ├── Visual.lua           # Визуальные функции
│   │   ├── Misc.lua             # Дополнительные функции
│   │   └── Settings.lua         # Управление настройками
│   └── Utils/
│       ├── Utils.lua            # Общие вспомогательные функции
│       └── Math.lua             # Математические утилиты
```

## 🚀 Использование

### В Delta Executor

```lua
-- Загрузить и запустить Main.lua
-- Delta загружает скрипт с GitHub или локально
-- Main.lua автоматически запускает всю систему
```

### Поток инициализации

1. **Main.lua** — точка входа, инициализация ProjectDelta
2. **Core/Loader.lua** — загрузка всех необходимых модулей
3. **Core/Config.lua** — загрузка конфигурации
4. **Core/Logger.lua** — инициализация логирования
5. **GUI/GUI.lua** — создание интерфейса
6. **Functions/Functions.lua** — инициализация функций

## 🔧 Структура модулей

Каждый модуль возвращает таблицу со своим API:

```lua
-- Пример структуры модуля
local Module = {}

function Module:Init()
    -- Инициализация
end

function Module:Load()
    -- Загрузка
end

return Module
```

## 📦 Модули

### Core (Ядро)
- **Loader.lua** — загрузка модулей из GitHub и управление зависимостями
- **Logger.lua** — логирование в консоль и файл
- **Config.lua** — хранение и управление настро��ками

### GUI (Интерфейс)
- **GUI.lua** — создание главного окна и управление интерфейсом
- **Theme.lua** — цвета, размеры, стили
- **Components.lua** — кнопки, слайдеры, переключатели
- **Tabs.lua** — вкладки (Player, Combat, Visual, Misc, Settings)

### Functions (Функции)
- **Functions.lua** — менеджер и координатор всех функций
- **Player.lua** — функции для игрока
- **Combat.lua** — боевые функции
- **Visual.lua** — визуальные функции
- **Misc.lua** — дополнительные функции
- **Settings.lua** — управление настройками

### Utils (Утилиты)
- **Utils.lua** — общие вспомогательные функции
- **Math.lua** — математические функции

## ✨ Особенности

✅ Модульная архитектура — легко добавлять новые функции

## 📝 Разработка

Для добавления новой функции:

1. Создать новый файл в `Functions/`
2. Реализовать функции в модуле
3. Зарегистрировать в `Functions/Functions.lua`
4. Добавить UI вкладку в `GUI/Tabs.lua`
5. Добавить тему в `GUI/Theme.lua` если нужно
